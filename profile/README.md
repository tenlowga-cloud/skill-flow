# Your profile folder

On surfaces other than Claude Code, `setup` writes your four profile files here: `PROFILE.md`, `TOOLS.md`, `VOICE.md`, `ROUTER.md`. They are yours and private. This folder's `.md` files are gitignored, so a fork of this repo never carries them by accident.

On Claude Code the same files live in `~/.claude/skill-flow/` instead.

Blank templates: `skills/profile/references/`.
