# Your profile folder

On surfaces other than Claude Code, `setup` writes your profile files here: `PROFILE.md`, `TOOLS.md`, `VOICE.md`, `ROUTER.md`, `STACK.md`, `BRAND.md` with your logo files in `brand/`, plus `BLUEPRINT.md` once `blueprint` has run. They are yours and private. This folder's `.md` files are gitignored, so a fork of this repo never carries them by accident.

On Claude Code the same files live in `~/.claude/skill-flow/` instead, and your operating file lives at `~/.claude/CLAUDE.md`.

Blank templates: `skills/profile/references/`.
