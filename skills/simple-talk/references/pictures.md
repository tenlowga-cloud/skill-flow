# Pictures

1. Read `TOOLS.md` from your skill-flow profile folder (`~/.claude/skill-flow/` in Claude Code, else `profile/` in this repo). If it is missing, say so once and ask the one question you need, or run `setup`. Use the image tool it lists.

1. Use the image tool in `TOOLS.md` (read it from your skill-flow profile folder, `~/.claude/skill-flow/` in Claude Code, else `profile/` in this repo). If it is missing, say so once and ask the one question you need, or run `setup`.
2. Ask for one simple illustration, four elements or fewer, no small print. Keep exact numbers out of the picture and in the sentences, because image models get text wrong.
3. Save it to a temp folder or the owning project, open it, and send it to the owner with the message.
4. Say "picture attached" in one sentence. The picture does not replace the words.

Prompt shape:

```
Simple flat illustration, white background, big clear shapes, no text except at most 3 short labels.
Show: [the one idea, described like a scene a child could draw]
Left side: [before / cause]. Right side: [after / effect]. One arrow between them.
```
